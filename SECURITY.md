# Reporting a security issue

Please report vulnerabilities using [GitHub private vulnerability reporting](https://github.com/GioPalusa/ScreenShotStudio/security/advisories/new). Include reproduction steps, affected versions and impact. Do not include real user documents, API keys or credentials. If private reporting is unavailable, contact the maintainer through [PALUSA](https://www.palusa.se) without publishing exploit details in a public issue.

Security fixes target the latest release. Official macOS updates use HTTPS and Electron's native code-signature verification. Project imports and file writes must preserve path confinement, revision checks, recovery drafts and atomic writes.
