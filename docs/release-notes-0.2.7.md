# Screenshot Studio 0.2.7

- Upload screenshots directly to App Store Connect after export, or upload a saved export later from the Upload view.
- Review every language and Apple screen group before upload. Existing groups can be kept or explicitly replaced.
- Choose Duo open, closed, or a mix within one shared 10-image group per language.
- Accept text, layout, and translation warnings without blocking upload; technical errors remain blocking.
- Confirm image receipt and placement order immediately. Apple continues processing in App Store Connect.
- Choose a destination folder for every Mac export.
- Get accurate text-fit explanations, unlimited lines with Max lines set to 0, and concise dropdown tooltips.
- Automatically check and correct translation meaning while keeping machine translations as drafts for human review.

Apple silicon (arm64), macOS 13 or later. Download the ZIP, unzip it, and move Screenshot Studio.app to Applications.
