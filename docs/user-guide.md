# Screenshot Studio user guide

## Get started

The app opens Home, showing a grid of recent projects with real artwork previews, names, edit dates and screen counts. Search in the sidebar, or sort by last opened, last edited or name. Preview rendering is read-only and does not create exports. Click the Screenshot Studio logo from any document to return here; pending saves are acknowledged before leaving the editor. Open a recent project, choose **Open project…**, or choose **New project…**. Opening a `.sss` file directly still opens that document. To create a project, name it, choose an App Store or Google Play destination, and select Midnight, Porcelain, Mint or Orchid — or choose your own background, text and accent colours. **Create project…** lets you choose where to save a portable `.sss` document. Choose **Replace** to create a fresh project over an existing one; the previous project is retained under **File → Restore Version…**. Cancelling leaves the welcome screen open. **New Project** brings the palette setup back; recent documents are available on the welcome screen. Opening a `.sss` file directly opens its editor.

**Import from Figma…** on Home creates a new project from all or selected views, after an editable preview and a save-location choice. You can also copy a Figma frame or selection and paste it on Home to start a new project without a Figma key. For an existing document, use **File → Import → From Figma…** or paste into the editor. A working read key is saved in macOS Keychain; its lifetime can be recorded as 1, 7, 30 or 90 days, or a custom date. Expired/revoked keys can be replaced in the same dialog.

1. **Choose your canvas.** Setup → Canvases offers store formats. Choose one size for the row, then choose **Portrait** or **Landscape** per screenshot in Overview or the editor toolbar. This swaps width and height for that screenshot in every language, without adding another canvas or rotating its devices. The export keeps one ordered row with each image’s actual dimensions. Custom format is for your own dimensions.
2. **Bring in screenshots.** New Apple projects start with a neutral **Generic frame**. For Apple hardware artwork, open **Setup → Frames**: **1. Download from Apple**, then **2. Drop your DMG here**. Upload in Media or drop an image onto the device. Select a device on the canvas to edit its **Details**: choose its screenshot, frame and fitting. The frame dropdown offers **No frame**, **Generic frame**, then matching frames, with **Get more frames** last. Use **Browse all frames…** to choose another device style. To create an Android or another Apple canvas, open **Setup → Canvases → ＋ Store format**.
3. **Design.** Select text, an image or a shape to edit its **Details** directly; move, resize and rotate layers on the canvas. **＋ Add screens** creates new screens. **Design → Load design…** changes the current screen, and **Save this design…** saves a reusable layout. **All designs** shows complete designs, device arrangements and connected series together. Filter by one screen or a set of 2–5 screens. Adjust **Gap** in the strip preview to allow for the space between store images; this is a design estimate, since the store controls its actual spacing. Choose screenshots in order, or use **Create screens from screenshots…** after importing several screenshots in Media. Split layers stay linked across the series; **Unique design** opts a slide out. Design contains reusable palettes.
4. **Translate.** Select a screenshot from the horizontal thumbnail row to edit its text in every language underneath. Scroll sideways or use Left/Right, Home and End to navigate. Switch between **Per screen** and **Per language**. Your editable text comes first; expand **Original** for a reference or use **Show original text** to compare all fields. Meaning checks show a short status with expandable details. The main Translate action defaults to **All screens**; a screen’s **More → Translate** action targets that screen. Add languages, mark text for review, and export/import review CSVs using stable screen and layer IDs. Project actions are in the native **File** menu.
5. **Export.** Checks run automatically when the export dialog opens and whenever you change the selected languages, canvases or slides. **All screens** is checked by default. Uncheck it to choose individual languages, sizes and screens. Issues appear before any images are written; expand **Export details** for storage information and additional controls. Fix the issues or choose **Export anyway** to include placeholders for missing images and keep all issues in the export report. RGB PNGs and an upload guide go into a dated folder, with format-first numbered filenames. CLI `--strict` still requires all checks to pass.

**Text fit:** Details checks the selected text object and explains whether it exceeds **Max lines**, the box width or the box height. Text can fit visibly inside its box while exceeding its configured line limit. If that is the only issue, **Allow 3 lines** (or the reported count) updates that object's line limit; ⌘Z undoes it. Set **Max lines** to **0** for unlimited lines; width and height still have to fit. The same explanation appears in export checks. **Typography → Text size → Fill frame** fits text to the box and ignores the manual line limit while preserving explicit line breaks.

**Overview** shows one scrollable row per language at the same preview size. Use the zoom slider or a custom percentage (10–200%), or **Fit to width** to fit the entire row as the window changes. Horizontal scroll and arrow buttons reveal the rest of a wide row; zoom is remembered on this Mac.

**Edit all screens:** the first button in the editor’s screen list opens the whole row as a shared canvas. Its screen count shows the scope. Right-click any screen thumbnail to duplicate or remove that screen, including while All screens is active. Copies keep every language and appear directly after the source in each language’s order. Removal asks for confirmation and can be undone. Objects added here can overlap multiple screens; editing one of these objects from an individual screen updates the same object everywhere. Images and other objects added on an individual screen remain local, even when they extend outside its edges. In All screens, object choices are grouped by numbered screen name, with a separate Across screens group for shared objects. Moving or resizing an existing object makes it shared by default. Screen edges stays available in both views; an explicit Keep on this screen choice is saved and respected even when moving the object in All screens. In a single-screen view, Details → Screen edges chooses Keep on this screen (crop at its edges) or Continue across screens (one linked object). ⌘C and ⌘V copy and paste selected objects, including independent text in every language; pasting in All screens creates shared objects, while pasting in a single screen creates local objects. Each canvas format has its own shared objects, while language-specific images and text remain supported. Design → Space between screens offers App Store, Google Play and Custom spacing. Every distance is shown in pixels at the exported screenshot size; Custom accepts a precise pixel value, including zero and decimals. New canvases default to their store; existing spacing is preserved. These are Studio preview presets, not fixed store specifications. Exports crop each screen and omit the gap. Pinch to zoom or press **0** to fit the row.

**Trackpad navigation:** pinch to zoom around the pointer in the editor and Overview. Scroll with two fingers to pan in either direction; small movements and momentum stay continuous. In the editor, press **0** to recenter and fit the canvas, or **− / +** to zoom from its current size. A mouse wheel pans too; hold **Control** to zoom or **Shift** to pan horizontally. Middle-button dragging also pans the editor. Navigation changes only your view, not the exported design.

**Editor panels:** use **Screens** and **Details** in the editor toolbar to show or hide the left screen list and right inspector independently. Both controls remain available when the panels are hidden, and your choices are remembered. The canvas fits the available space; a manual zoom and pan are preserved. The Mac **View** menu offers the same controls: **⌥⌘1** for Screens and **⌥⌘2** for Details.

**Help → Get Started Guide** is always available. **View → Keyboard Shortcuts** lists editing shortcuts. ⌘Z / ⇧⌘Z undo and redo. Autosave uses atomic writes, conflict checks and recoverable drafts. Save Version and Recover Automatic Backup open separate recovered documents.

Apple bezel artwork is not bundled with the app. Setup → Frames has two prominent steps: **1. Download from Apple** opens Apple Design Resources; **2. Drop your DMG here** accepts the downloaded disk image (or use **Choose DMG…**). macOS presents any agreement included in the image; accept it there to continue, or decline to cancel. PNGs from its folders appear in a preview where you select the frames to install in the app’s shared library. They become available in every project on this Mac. Frames used by a design are also retained inside its .sss package so it stays portable. Photoshop files are ignored. Studio waits for the mounted volume even if Finder opens or macOS publishes the disk late. Images mounted by Studio are ejected after reading; already mounted images are left in place. **Import PNGs…** remains available for individual files. Imported frames and artwork already stored in existing projects stay intact. Generic Studio illustrations remain available. Duo illustrations are no longer offered; existing projects retain their saved frame choices. New documents contain no app screenshots or imported artwork. Existing `.screenshotstudio` documents remain compatible. User projects and the historical local fixture in `project/` are excluded from public source and every packaged build. Tests use synthetic documents.

## Export screenshots

In the Mac app, choose **Export…**, review the selected images and checks, then start the export. A native folder picker opens every time. Choose a folder outside the project package; an additional copy is saved in its own dated subfolder with PNGs, a manifest and upload guide. The same completed run is retained in the project’s export/ folder and is listed under Saved exports in Export and Upload after reopening. Save As includes captures, artwork and completed exports. Cancelling the folder picker returns to the export options without writing export files. **Show in Finder** reveals the completed export. Browser development mode and CLI exports use their configured output directory.

## Translation and importing designs

**Translate…** in Translate or text Details accepts an OpenAI or Claude API key for the current dialog. Choose the target language and screens. **Translation options** contains the original language and whether to fill missing text or replace it. Provider, model and API key settings expand when setup is needed. Results update that language, remain draft for review, and can be undone.

**Overview → Import designs…** (also in Media) accepts PNG/JPEG exports, folders and ZIPs from other screenshot tools. Images remain image layers; fastlane Framefile sources also import editable text and generic devices. Preview the language mapping before adding slides. [Supported formats, limits and research](imports-and-translation.md).

**Paste from Figma:** copying layers in Figma and pressing **⌘V** in the editor pastes editable content directly. If fonts are unavailable, only the font-resolution dialog appears. If Figma omitted image files, **Missing images** lets you attach PNG/JPEG/WebP replacements, skip individual images or skip all unresolved images and paste the rest. Cancelling leaves the document unchanged; the completed paste is one Undo step. Figma links and **Import from Figma…** keep the view-selection and preview workflow.

**SVG and WebP:** add either format through the image library, drag a file onto **Add as graphic**, or paste it onto the canvas. SVG becomes editable vector and text layers; positioned Illustrator text spans retain their placement and typography. Illustrator copy/paste uses its native SVG representation when available and centres the selected artwork without empty artboard margins. WebP remains a portable image layer. Each completed paste or file addition can be undone; missing SVG fonts use the font-resolution dialog.

**Illustrator text boxes:** when Illustrator supplies formatted text without SVG, paste imports that text before the PNG preview. A box with consistent styling becomes one editable text layer with its paragraphs and soft line breaks intact. Font family, weight, italics, size, leading and tracking are retained; text is fitted to the canvas if necessary. Mixed styles remain editable text parts. Missing fonts open the font-resolution dialog, and cancellation leaves the document unchanged. The complete paste is one Undo step.

## Details follows the selection

With no object selected, **Details** shows document facts and shortcuts to settings, fonts and the layer list. Selecting an object replaces those controls with its own properties. Position and Effects come before the type-specific controls, so shadows are available without scrolling past fills, gradients or paths. Screen-edge behaviour and secondary object actions are collapsible sections.

When a Figma import, native Figma paste or SVG paste uses unavailable fonts, **Missing fonts** lists them before anything is added. Add original **.ttf/.otf** files directly in the dialog, or choose **Replace fonts…**, select one replacement for the remaining missing families and confirm **Use replacement**. The chosen family is used in the preview and saved native text; the text remains editable. Cancel leaves the document unchanged. Font rows contain only names and status. Use the shared **Add fonts…** action below the list. The replacement choice appears only after selecting **Replace fonts…**. The required-font list stays visible after a font-file import and shows which families are resolved and which faces still need files. Added files list the requirements they match; unrelated files are explicitly identified. Added original font files travel with the project. Fonts available only on the current Mac still need collecting for portability.

## Canvas tools

The vertical tool panel sits along the left edge of the workspace, beside the screen list. **V** selects and moves objects; **A** selects vector points. **R** draws a rectangle, **O** draws an ellipse or circle, **L** draws a line, and **P** activates the vector pen. **T** adds editable text; **I** opens the image picker. The compact icon-only toolbar uses 17 px icons in a 40 px rail. Hover over a tool for its name and shortcut. The filled arrow selects whole objects; the outlined arrow selects points. The overlapping squares at the bottom show and edit the selected shape’s fill and outline. Text selections expose their fill colour. With nothing selected, the squares set the next shape’s appearance. Different paints in a multiple selection show a striped mixed swatch; a colour change applies to all selected shapes as one Undo step. Imported gradient fills show a gradient preview; picking a colour replaces the displayed fill with a solid colour. Gradient swapping is unavailable because outlines currently support solid colour. Click a square to select it; double-click it or press Enter while it is focused to open the colour picker. The solid square sets the fill and the hollow square sets the outline. **No colour** (the red slash) removes the active paint; **Use colour** restores its saved colour. The swap button exchanges both paints, including “no colour”. **X** switches between fill and outline, **Shift+X** swaps them, and **/** chooses no colour. **px** shows a compact numeric thickness field. Click or focus it to expand a horizontal slider and an exact numeric field. Drag the slider or type a value; both fields stay synchronised. Escape or clicking outside closes the expansion. The selected object’s outline updates immediately; with no selection, the value applies to the next shape. Details → Outline uses the same expandable control. Creation defaults are remembered separately from edits to selected objects. Removing a selected fill keeps its original paints for restoration, including after reopening the project.

Drag on the canvas to draw a shape. Hold **Shift** for a square, circle or line constrained to 45° increments, and **Option** to draw from the centre. The pen creates corners with clicks and Bézier handles with drags. Click the first point to close a filled shape, or press **Enter** to finish an open stroked path. **Escape** cancels an unfinished drawing; Backspace or ⌘Z removes the last draft pen point. A finished drawing is one Undo step. Choose **V** to return to moving/resizing objects, or **A** to reshape a vector. The tools also work in **All screens**, preserving the position where you draw.

## Edit imported vectors

In Details, **Corner radius**, each individual corner value, and **Blur** use the same expandable numeric control as outline width. Click the value for a slider and an exact px field; Escape or clicking outside closes it. Corner radii are limited by the shape’s dimensions. Changes can be undone.

Every object type offers **Details → Effects → Add shadow**, including text, images, devices, shapes and paths. Choose one of the nine visual previews in the 3 × 3 **Presets** grid (Subtle, Soft, Floating, Crisp, Dramatic, Lifted, Left, Long or Glow). The selected preview is outlined. Open **Settings** to adjust colour, opacity, distance, direction and blur/size. Drag the angle dial or use its arrow keys (Shift for 10°); 0° points right and 90° points down. X/Y offsets remain available in Advanced. Values stay synchronised; zero distance retains the chosen direction. Presets remain editable and are one Undo step. Numeric values expand into sliders and exact fields; negative offsets move the shadow left or up. **Remove shadow** keeps the settings for later restoration.

Rectangles and closed polygon paths show small circular corner widgets inside their corners. Drag inward to increase the radius or outward to reduce it. With the upper **Select (V)** pointer, dragging a widget adjusts all corners. With the lower **Edit points (A)** pointer, it adjusts only that corner. Corner drags are one Undo step; Escape cancels a drag. Rectangles also expose separate corner values in Details. Open paths and smooth curved paths have no polygon corner widgets. Rounding preserves editable vector paths and paint coordinates.

Select a vector and choose **Details → Shape → Edit points**, double-click it on the canvas, or press Enter. Drag square points and round Bézier handles to reshape it. Select a smooth interior point to reveal its two handles. **Link handles** keeps them collinear while retaining the opposite handle’s length; hold **Option/Alt** during a handle drag, or turn off **Link handles**, to move one independently. **Smooth** creates a smooth point with handles; **Corner** collapses the handles. **B** or **Bend segments** offers direct segment bending as a supplementary action. The point and gradient tools sit above the canvas and stay clear of the artwork while zooming or panning. **+** selects Add point: click a segment to insert a point. **−** selects Remove point: click an anchor to remove it. **A** returns to selecting and moving points. The canvas uses a consistent set of original desktop-style cursors, with compact symbols for selection, moving, drawing, point edits, resize, rotation and panning. Menus, toolbars and inspector controls use system pointers. Hold **Shift** over a segment to see **+**, then click to add a point. Hold **Option/Alt** over an anchor to see **−**, then click to remove it. Releasing the modifier restores the current tool cursor. Double-clicking an edge also adds a point; selecting a point and pressing **Delete/Backspace** removes it. Each insertion or deletion is one Undo step. Option-drag still moves points or unlinks curve handles without deleting them. **Corner**, **Smooth** and **Delete point** act on the selected point; arrow keys nudge it, with Shift for 10 pixels. Choose **Done** or press Escape to return to moving and resizing the object. Every drag can be undone with ⌘Z. Object resize and rotation handles take precedence over drawing tools, so you can adjust a newly drawn object before switching back to V.

**Fill** edits solid colours and linear/radial gradients, including each stop’s colour, position and opacity. **Edit gradient on canvas** exposes its direction handles; radial gradients also have a width handle. **Outline** edits width, colour and inside/centre/outside alignment. **Blur** has a slider and a precise pixel field. Multiple imported fills remain separate. SVG code is tucked away in **Advanced path data** and is unnecessary for visual editing.

## Right-click menus

Right-click an empty canvas area for **Paste** or **Add → Text, Image… and Shapes → Rectangle, Ellipse / circle or Line**. New items are placed at the pointer and shapes use the drawing defaults. Vector pen starts the pen tool. Paste supports editable Studio objects, plain text, images, SVG and Figma content through the same pipeline as ⌘V.

Right-click an object on the canvas or in Layers for **Arrange**, **Align**, **Transform**, **Appearance** and **Vector** submenus. Vector → Combine shapes contains Union, Subtract, Intersect and Exclude. Appearance offers copy/paste appearance and Add/Remove shadow. Grouping, rotation, flips, masking, duplication, visibility, locking and deletion are available where applicable. Right-clicking an object already in a multiple selection keeps that selection. Stacking moves selected objects together while retaining their relative order.

Hover or click a submenu, or press **Right** to open it. **Up/Down**, **Home/End** and typing a command's first letters navigate; **Enter** runs it. **Left** or **Escape** closes the current submenu; Escape at the top level, Tab or clicking outside dismisses the menu. Submenus open to the left when needed to stay inside the window.

## Appearance, spacing and shape operations

Choose **Copy appearance** and **Paste appearance** in Details, the context menu or the Mac Edit menu. **⌥⌘C** copies the active object's compatible fills, outline and effects; **⌥⌘V** applies them to the selection without replacing its geometry or content. Text-to-text transfer also copies typography. Image fills can be transferred within the same project.

Shift-click objects to edit them together. Details offers common opacity, blur, fill, outline, rectangle corners, text typography and shadows where applicable. **Mixed** indicates different values. Each change is undoable; a slider drag is one Undo step.

Dragging an object shows measured edge gaps with opaque, high-contrast labels and 2 px measurement lines and snaps to equal spacing between neighbouring objects. Hold **Option** while hovering another object to inspect distances. Hold **⌘/Ctrl** during a drag to disable snapping.

Select at least two objects and choose **Use as mask** or press **⌥⌘M**. The frontmost object masks the others. Both the mask and its contents remain editable objects. **Release mask** restores their previous grouping and visibility. The objects must belong to the same screen, or all be shared objects.

For two or more closed shapes, Details offers **Union**, **Subtract**, **Intersect** and **Exclude**. Subtract removes the front shapes from the backmost one. The result is an editable vector path using the backmost shape's appearance; use **Edit points** to reshape it. One Undo restores the original objects. Operations require 2–100 unlocked shapes on the same screen and in the same clipping group. An empty result leaves the document unchanged.

This is an open-source community project under the [MIT license](../LICENSE). See [CONTRIBUTING.md](../CONTRIBUTING.md) to get involved and [SECURITY.md](../SECURITY.md) to report vulnerabilities. Use Node 22.12 or newer (Node 24 recommended):

```sh
npm ci
```

## Apple distribution

Open **Screenshot Studio.xcodeproj**, choose **Screenshot Studio → My Mac**, and **Product → Archive**. Xcode packages Electron for Apple silicon (arm64), signs its nested code with Developer ID and Hardened Runtime, then seals the app. End users do not need Node. Official releases use the maintainer’s Developer ID team. Set your own signing team for a fork.

In Organizer choose **Distribute App → Direct Distribution**, wait for Apple acceptance, then **Export Notarized App**. Each changed build needs a new archive and notarization; `npm run package` is an ad-hoc developer build. No credentials are stored here. Versioned verification records live in `distribution/RELEASES.md`.

```sh
codesign --verify --deep --strict "/path/to/Screenshot Studio.app"
xcrun stapler validate "/path/to/Screenshot Studio.app"
spctl --assess --type execute --verbose=2 "/path/to/Screenshot Studio.app"
```

[Apple notarization](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution) · [Electron code signing](https://www.electronjs.org/docs/latest/tutorial/code-signing)

### App appearance

Choose **System**, **Light** or **Dark** in **View → Appearance**. System follows your
Mac's appearance; an explicit choice stays in effect until you change it.
The preference is shared across app windows and remembered between launches.
It changes the workspace colours, while your screenshot artwork keeps its own
palette and exports the same way in either appearance.
