## What's new

- **Bring designs into the editor.** Import Figma files or paste Figma content as editable layers. Paste Illustrator artwork with editable text, with improved SVG and WebP support.
- **Draw and refine vectors.** New drawing and Bézier tools, live corners, editable boolean operations, masks and clipping, plus shared fill, stroke and effect controls.
- **Organize complex designs.** Layers are grouped by artboard with named, collapsible groups. Selection-aware context menus and a focused Details panel make individual objects easier to find and edit.
- **Work comfortably on the canvas.** Collapsible panels, contextual cursors, clearer distance labels and visual shadow presets with polar controls.
- **Find your projects faster.** A Home gallery with project previews, in-app Figma import and portable project fonts, including missing-font review.
- **Give your AI agent more control.** Expanded MCP tools cover native editing, layer hierarchy and named groups, with screenshot text review and font coverage checks.
- **Updated runtime.** Electron 44.11.3 and dependency security fixes.

## Download

Apple silicon (arm64), macOS 13 or later. Download the ZIP below and move **Screenshot Studio.app** into **Applications**. The official app supports **Screenshot Studio → Check for Updates…**.

The app is Developer ID signed and notarized by Apple. A SHA-256 checksum is attached.
